# Job Job Job
## Program
Job Job Job is a web demo of a non-profit middle and high school job listing service. It is meant to provide job and/or volunteering opportunities for students in 6th - 12th grade. The demo also features a working Google Form link to "partner" with the non-profit. This demo is not meant to act as an official listing site for jobs and should be taken as a harmless demo.
